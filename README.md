# alexgaribaldi.com

Personal portfolio website for Alexandra Garibaldi.

## Stack

- React 19
- TypeScript
- Vite
- Canvas 2D (animated ocean background)
- GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushes to `main` automatically deploy to GitHub Pages via GitHub Actions.

Live at [alexgaribaldi.com](https://alexgaribaldi.com)
